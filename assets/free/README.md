# The free set

Stand ins for everything in `assets/roccat/`, same file names and sizes, made by `tools/assets/placeholders.py`. Nothing in here came from ROCCAT. They are under the same license as the code (GPL-3.0-only).

For now they are all empty: see-through pictures with nothing on them, until we figure out how to make our own. The gui still draws keys, markers and colours by itself, there is just no device artwork under them. If you can draw: pictures of your own are very welcome.

`-DROCKCAT_ROCCAT_ASSETS=OFF` makes the build use this folder.
